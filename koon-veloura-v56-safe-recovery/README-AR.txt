حزمة Veloura V56 Safe Recovery
==============================

هذه الحزمة تعالج مشكلة عدم تحميل الموقع بعد الحزمة السابقة.

ماذا تفعل؟
- تحذف include الخاص بملف veloura-product-ui-contract.twig.
- تحذف الملف المكرر الذي كان يحتوي 639 سطراً من Twig/CSS/JS.
- تصلح قراءة selected.value لخيار حواف العرض السريع.
- تصلح مسافة زر السلة يمين/يسار داخل بطاقات المنتجات ومنتجات قد تعجبك.
- تفصل حالات شريط الشراء في الجوال: ثابت، مثبت كامل، مثبت مصغر.
- تمنع الوضع الزجاجي عن الشريط العادي داخل بيانات المنتج.
- تستخدم نظام V54 الموجود أصلاً بدل إنشاء نظام موازٍ جديد.

التشغيل:
node .\INSTALL-VELOURA-V56.js
node .\VERIFY-VELOURA-V56.js
git restore -- public
pnpm production
salla theme preview
