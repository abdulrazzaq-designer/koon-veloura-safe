# إصلاح عقد حواف المنتج والعرض السريع — Veloura

هذا التصحيح مخصص للمستودع `koon-veloura-safe`، ويعالج أربع مجموعات مترابطة من المشاكل دون تغيير أسماء إعدادات الثيم الحالية.

## ما الذي تم إصلاحه؟

1. **الحواف العامة داخل صفحة المنتج**
   - تطبيع قيمة الإعداد سواء رجعت كقيمة مباشرة أو `value` أو `selected.value` أو مصفوفة خيارات.
   - تمرير الحواف نفسها للعناصر التفاعلية والكروت والصور المصغرة وشريط الشراء.
   - خيار `sharp` يساوي فعلياً `0px` ولا يبقى تحته تدوير ثابت.

2. **العرض السريع Quick View**
   - فصل حواف النافذة عن حواف أزرارها.
   - إزالة اعتماد الأزرار على `999px` الثابت.
   - إلغاء طرح `8px` من حواف منطقة الصورة؛ لأن ذلك يكسر خيار الحواف الحادة.
   - تطبيق الإعداد على النسختين: `.veloura-quick-view-modal` و`.veloura-qv-full`.

3. **أزرار بطاقات المنتج وبطاقات “قد يعجبك”**
   - تطبيق الارتفاع، المسافة الأفقية والمسافة السفلية من نفس الإعدادات الموجودة.
   - حساب العرض نسبةً إلى الحافة الخارجية للبطاقة، وليس إلى الحاوية الداخلية فقط.
   - اجتياز الـShadow DOM المفتوح ومراقبة البطاقات التي تُحمّل لاحقاً داخل `salla-products-slider`.
   - تصحيح الزر الحقيقي داخل مكونات سلة، وليس غلاف المكوّن فقط.

4. **شريط الشراء على الجوال**
   - الحالة العادية داخل الصفحة: ألوان الثيم الطبيعية، بلا زجاج.
   - التثبيت المصغّر: داخل الشاشة بمسافة `12px`، مرتفع عن الأسفل، وكل الحواف تتبع الإعداد العام.
   - التثبيت غير المصغّر: بعرض الشاشة وملاصق للأسفل، مع تدوير الزاويتين العلويتين فقط.
   - الزجاج العام يُطبّق فقط عندما يكون الشريط مثبتاً على الجوال.

## طريقة التطبيق الموصى بها

من جذر المستودع:

```bash
git apply --check koon-veloura-ui-fix.patch
git apply koon-veloura-ui-fix.patch
```

ثم راجع الملفات المتغيرة:

```bash
git diff -- src/views/layouts/master.twig \
  src/views/pages/product/single.twig \
  src/views/partials/veloura-product-ui-contract.twig
```

## الملفات المتغيرة

- `src/views/layouts/master.twig`
  - إضافة include واحد قبل `</body>`.
- `src/views/pages/product/single.twig`
  - إزالة أصناف الزجاج الدائمة من شريط الشراء، وإضافة `data-veloura-purchase-bar`.
- `src/views/partials/veloura-product-ui-contract.twig`
  - عقد الإعدادات النهائي، CSS للحالات، ومعالجة Shadow DOM والتحميل المتأخر.

## سيناريو اختبار القبول

1. اختر الحواف العامة `sharp` وافتح صفحة منتج:
   - شريط الشراء، الخيارات، الكروت والصور المصغرة المقصودة يجب أن تكون `0px`.
2. اختر Quick View = `sharp`:
   - النافذة وأزرارها يجب أن تستجيب لإعداد كل منهما بلا حواف ثابتة.
3. اضبط مسافة زر البطاقة يمين/يسار إلى `0`:
   - زر بطاقة التصنيف وزر بطاقة “قد يعجبك” يجب أن يصلا إلى نفس حافة البطاقة.
4. غيّر ارتفاع زر البطاقة:
   - افحص البطاقة العادية وبطاقة المنتجات المقترحة بعد اكتمال تحميل السلايدر.
5. على جوال بعرض أقل من `640px`:
   - مصغّر مفعّل: الشريط داخل الشاشة ومرتفع وكل الزوايا متساوية.
   - مصغّر معطّل: الشريط كامل العرض، الزوايا العلوية فقط مدوّرة.
   - تثبيت معطّل: الشريط داخل الصفحة وبألوان الثيم الطبيعية وبلا Blur.
6. فعّل الوضع الزجاجي العام:
   - يجب ألا يظهر على الشريط العادي، ويظهر فقط على الشريط المثبت بالجوال.

## التحقق المنفّذ

- فحص صحة JavaScript عبر `node --check`.
- فحص توازن أقواس CSS وكتل Twig.
- إنشاء الرقعة من نسخة المستودع الحالية والتحقق منها بواسطة `git apply --check` ثم تطبيقها على نسخة نظيفة بنجاح.
