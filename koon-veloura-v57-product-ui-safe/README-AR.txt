VELOURA V57 — إصلاح واجهة المنتجات الآمن

الإصلاحات:
- إطار 7px حول زر قراءة المزيد بلون خلفية الموقع.
- حواف الصورة المصغرة النشطة تتبع الحواف العامة، بما فيها الوضع الحاد.
- إزالة V56 المسبب لتضخم صور بطاقات التصنيف بشكل مستمر.
- استعادة خلفية وألوان إضافة للسلة واشتري الآن داخل Shadow DOM.
- تطبيق عقد بطاقة المنتج على جميع البطاقات التي يتم تحميلها لاحقاً.
- جعل المسافة السفلية 0 قيمة حقيقية حتى حافة البطاقة.
- الحفاظ على حالات شريط الشراء في الجوال والزجاج فقط عند التثبيت.
- إضافة خيارين: تفعيل منتجات شاهدتها مؤخراً، وربطها بإعدادات منتجات قد تعجبك.

التنفيذ:
1) انسخ INSTALL-VELOURA-V57.js و VERIFY-VELOURA-V57.js إلى جذر الثيم.
2) شغّل:
   node .\INSTALL-VELOURA-V57.js
   node .\VERIFY-VELOURA-V57.js
   git restore -- public
   pnpm production
   salla theme preview

ينشئ المثبت نسخة احتياطية أول مرة داخل:
