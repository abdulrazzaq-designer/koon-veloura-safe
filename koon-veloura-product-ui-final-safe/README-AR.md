# إصلاح واجهة منتجات Veloura — النسخة النهائية الآمنة

هذه الحزمة تعدّل الملفات الأصلية التالية فقط:

- `src/views/layouts/master.twig`
- `src/views/pages/product/single.twig`
- `twilight.json`

وتنشئ نسخة احتياطية قبل التعديل داخل:

```text
.veloura-product-ui-final-backup
```

## الإصلاحات

- جعل مسافة زر السلة يمينًا ويسارًا وأسفل البطاقة تستجيب للقيمة `0` فعليًا.
- توحيد بطاقات التصنيفات و«قد يعجبك» و«شاهدتها مؤخرًا» باستخدام بطاقة المتجر المخصصة.
- إزالة أكواد القياس المستمر V35 وV54 التي كانت تسبب حركة زر السلة أو تضخم الصور.
- تطبيق التنسيق من أول تحميل، مع محاولات محدودة فقط دون `MutationObserver` أو `ResizeObserver`.
- تثبيت زر قراءة المزيد في منتصف الحافة السفلية وإضافة إطار `7px` بلون خلفية الموقع.
- جعل إطار الصورة المصغرة النشطة يتبع الحواف العامة، ومنها الحواف الحادة `0px`.
- إعادة ألوان وخلفيات زر إضافة للسلة وزر اشترِ الآن، ومنع قص الزر السريع.
- فصل شريط الشراء العادي عن المثبت: الزجاج يعمل فقط عند التثبيت على الجوال.
- تشغيل خيار تصغير الشريط المثبت مع مسافة جانبية وسفلية `12px` وحواف كاملة.
- إضافة سويتش إظهار المنتجات المشاهدة مؤخرًا وسويتش ربطها بإعدادات «قد يعجبك».
- إضافة مسافة آمنة أعلى الفوتر في صفحة المنتج.
- إصلاح قراءة `selected.value` لإعدادات حواف البطاقة والصورة والزر والعرض السريع.

## التثبيت

من جذر الثيم شغّل:

```powershell
node .\INSTALL-VELOURA-PRODUCT-UI-FINAL.js
node .\VERIFY-VELOURA-PRODUCT-UI-FINAL.js

git restore -- public
pnpm production
salla theme preview
```

لا تكمل إلى `pnpm production` إذا ظهر `INSTALL ERROR` أو `FAIL`.

## التراجع

لاستخدام النسخة الاحتياطية التي أُنشئت قبل التثبيت:

```powershell
node .\RESTORE-VELOURA-PRODUCT-UI-FINAL.js

git restore -- public
pnpm production
```
