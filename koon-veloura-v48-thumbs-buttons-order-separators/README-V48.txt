VELOURA QV V48
===============

الإصلاحات:

1) الصور المصغرة أسفل صورة المنتج:
- تعود قابلة للحركة يمينًا ويسارًا باللمس، سحب الماوس والتراكباد.
- تبقى أفقية وأسفل الصورة.
- لا يعاد تفعيل خيار الصور الجانبية.

2) إضافة للسلة واشتري الآن داخل صفحة المنتج:
- إزالة منطق width:0 القديم الذي كان يخفي سطح الأزرار.
- إضافة للسلة: خلفية لون زر بطاقة المنتج المخصص، لون النص المخصص، الحواف المخصصة والنص في المنتصف.
- اشتري الآن: لون المتجر الأساسي بشكل Outline.
- لا يتم نقل عناصر Salla أو تعطيل النقر.

3) ترتيب تفاصيل المنتج:
- عنوان القسم يظهر فوق السويتش، وليس داخله.
- حقول الترتيب تظهر فقط عند تفعيل السويتش.
- عند إغلاق السويتش يحذف runtime جميع قيم order ويرجع الترتيب الطبيعي.

4) القائمة السفلية المثبتة على الجوال:
- خطوط تقسيم خفيفة شفافة بين السعر والكمية.
- خط عمودي خفيف بين إضافة للسلة واشتري الآن عند وجودهما معًا.

التنفيذ:
node .\INSTALL-QV-V48.js
node .\VERIFY-QV-V48.js
git restore -- public
pnpm production
salla theme preview
