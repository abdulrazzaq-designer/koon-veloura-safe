Veloura Quick View V36 — Glass icon fix
========================================

هذا الإصلاح يربط خيار "تفعيل الشكل الزجاجي لأزرار البطاقة والعنوان الترويجي"
بأيقونة العرض السريع الموجودة فوق صورة المنتج، بنفس خصائص أيقونة المفضلة.

ما يتغير:
- أيقونة العرض السريع فوق الصورة تصبح زجاجية عند تفعيل الخيار.
- نفس الخلفية والحدود والبلور والظل ولون الأيقونة المستخدم للمفضلة.

ما لا يتغير:
- زر العرض السريع الموجود تحت إضافة السلة يبقى زرًا عاديًا بلونه المحدد.
- نافذة العرض السريع لا تتأثر.
- لا يتم تعديل twilight.json أو أي إعدادات.

التنفيذ:
1) انسخ INSTALL-QV-V36.js و VERIFY-QV-V36.js إلى جذر الثيم.
2) شغل:
   node .\INSTALL-QV-V36.js
   node .\VERIFY-QV-V36.js
   git restore -- public
   pnpm production
   salla theme preview
3) نفّذ Ctrl + F5 في صفحة المعاينة.
