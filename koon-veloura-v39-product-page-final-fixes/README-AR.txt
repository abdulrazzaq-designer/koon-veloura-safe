Veloura Quick View V39 — إصلاحات صفحة المنتج النهائية

الإصلاحات:
1) زر إضافة السلة في منتجات قد تعجبك يأخذ قيمة سلايدر يمين/يسار بدقة؛ القيمة 0 تصل إلى حافتي البطاقة.
2) نبض حالة التوفر أصبح نبضًا مرئيًا بنقطة وحلقة متوسعة.
3) شريط إضافة السلة المثبت في الجوال أصبح فوق صور الصفحة والفوتر والمنتجات المقترحة، وتبقى قائمة التصنيفات فوقه.
4) كود الخصم وعدّاد مرات الشراء يقرآن القيمة المحفوظة selected قبل القيمة الافتراضية value.
5) لا توجد مراقبة عامة للصفحة؛ المراقبة محصورة في المنتجات المقترحة عند تحميل عناصر جديدة.

التثبيت:
node .\INSTALL-QV-V39.js
node .\VERIFY-QV-V39.js
git restore -- public
pnpm production
salla theme preview

بعد فتح المعاينة استخدم Ctrl + F5 مرة واحدة.
