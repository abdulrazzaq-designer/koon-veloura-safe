Veloura Quick View V40 — الصور المصغرة والعداد الثابت وتوضيح الكوبون

التعديلات:
1) إصلاح خيار موضع الصور المصغرة في اللابتوب باستخدام خصائص Salla الرسمية vertical-thumbs و thumbs-config.
2) عند اختيار "على الجانب الأيمن" تصبح الصور عمودية في اللابتوب، وتبقى أسفل الصورة في الجوال.
3) حذف خيار "تفعيل عداد متحرك من الصفر" نهائياً وحذف JavaScript الخاص بالحركة؛ يظهر العدد الحقيقي مباشرة.
4) توضيح إعداد كود الخصم: لا يظهر الصندوق إلا عند تفعيل الخيار وكتابة كود غير فارغ.
5) كود الثيم يعرض الكوبون وينسخه فقط؛ يجب أن يكون الكود نفسه منشأ ومفعلاً داخل كوبونات المتجر حتى يعمل عند الدفع.
6) لا توجد مراقبة مستمرة للتمرير أو DOM؛ تحديث الصور المصغرة يحصل عند التهيئة وعند انتقال الشاشة بين الجوال واللابتوب فقط.

التثبيت:
node .\INSTALL-QV-V40.js
node .\VERIFY-QV-V40.js
git restore -- public
pnpm production
salla theme preview

بعد فتح المعاينة استخدم Ctrl + F5 مرة واحدة.
